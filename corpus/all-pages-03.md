== 角色介绍 ==

工程师的具体诞生时间已不可考。与其余[[管理者]]类人的形态不同，工程师的形态可随意变化，通常为各种结构复杂的机械设备。它利用这种特性，将自己的身体作为工具使用。

工程师没有灵魂，但它仍有意识、感情、记忆。显而易见的，'''它并非源自琉诺菲拉的生物'''。

作为[[管理者]]，工程师的职责是'''设计与制作灵魂之外的一切事物'''。琉诺菲拉的法则也该归由工程师管理，但它将这件事交给了自己的造物[[法官]]。

工程师将自己的职责视为必须完成的使命，大部分时间它都在维护琉诺菲拉。

工程师休息时会坐在[[太阳]]边，自言自语着晦涩的词句。

== 事迹 ==

[[众星历]]-3612年,工程师建成了琉诺菲拉的山川草木，定下自然的法则。随后，它从太阳的核心中打捞出了[[园艺师]]。

众星历-3590年,园艺师赋予万物灵魂。为对这些灵魂进行管理与回收，[[工程师]]创造了[[天界]]与[[天界#白匣子|白匣子]]。
与灵魂一同诞生的还有故事。工程师开始分批次制作[[星星]]，用于储存琉诺菲拉的故事。

众星历-3510年,工程师制造了第一批动物，将之投放到琉诺菲拉的大地。

众星历-1397年，工程师制造了[[人]]。在这之后，它发现人过度的恶行会使魂质受到[[魂质污染|污染]]，而这种污染难以被天界净化。为此，工程师创造了[[地狱]]与[[清扫者]]。

众星历214年，为关押[[塔尔塔之龙]]，工程师建造了[[深黯之底]]。此后，这一空间也被用于囚禁其他难以处理的灵魂。

# 概念灵

- 原站版本时间：2026-09-13T13:02:05Z

概念灵是园艺师意料之外的生命，它们没有预先分配的灵壳。壳外的或死者的魂质受某种强烈的思想或情感吸引（为何会被吸引目前未知），最终聚成一团，就形成了概念灵。概念灵有三种产生方式。这里暂时先用事例说明。
1.成片成片的人饿死在东北大陆的土地上。其中有几个灵壳破碎者。他们的魂质被哀怨吸引聚在一起，形成了饥饿的概念灵。
2.维德拉恩王国流传着关于战争之神的虚构故事。故事被人们信以为真，战争前夕的部队杀死牲畜向战争之神献祭以求胜利。这种期待吸引死去牲畜的魂质聚集，最终形成了战争的概念灵。
3.人开始测算天文，自以为是地将正十二面体认作构成宇宙的基本元素以太，并以此对世界展开解释。这个学论大范围流传之时，人的魂质也因傲慢之罪而受污染。而被污染覆盖掉的那部分魂质最终聚集形成了傲慢的概念灵普罗维登斯。
概念灵可以借由他们的魔力放大对某种概念的认知，亦或是一定程度上的扭曲现实向相关概念偏离。
因为没有灵壳，概念灵的魂质不断上浮，它们的记忆和形态也因此极其不稳定，认知模糊，当魂质流尽之时，概念灵就会消失。部分概念灵为了对抗这种状况，会主动寻找灵壳，钻入其中，这被称为附身。没有附身的概念灵是灵体状态。通常来说，概念灵不能直接附身有已有魂质的生物。

深黯之底是一个类似沙盒的隔离空间，其中只有无边的黑暗。这里的囚徒除'''[[灵魂#同频连接|同频连接]]'''外，无法以任何手段干涉现世。每位囚徒之间亦被隔离，'''难以认知到彼此的存在'''。

== 功能 ==

深黯之底专用于囚禁其他系统难以处理的[[灵魂]]。如：

*罪孽过重，无法被[[天界]]净化，也无法在[[地狱]]完成赎罪的灵魂。

*过于强大或灵活，难以被[[天界]]和[[地狱]]捕获的灵魂。

*极端危险的灵魂。

# 灵魂

- 原站版本时间：2026-09-25T18:05:56Z

琉诺菲拉的'''所有非加工品皆有<span class="rainbow-text">[[灵魂]]</span>'''。其中包括生物与自然中的无机物。'''一般情况下，灵魂是不可视的，且会直接穿过其他物体'''，需进行验灵仪式后摘出体内，才可肉眼观察并触碰。

灵魂看起来像个装着浅白液体的彩色玻璃小球，通常来说，智慧程度越高的生物灵魂就越大。

在生物死亡或无机物被破坏后，其灵魂会自主上浮，最终前往[[天界]]。

== 结构 ==

动物的灵魂由'''壳'''和'''质'''两部分组成。植物、无机物等无意识个体只有灵壳而无灵质。

但也有例外存在：

*持续受日光照射数千年后，植物与无机物的灵壳中，也有极低的概率自然堆积出浑浊的“魂质”。详见：[[自然灵]]。

*大多数[[概念灵]]仅有魂质而无灵壳。
=== 灵壳 ===

灵魂外侧的硬壳，看起来像有色玻璃，直接决定了'''灵魂的颜色'''。

壳是有形的，可使用'''[[灵魂侦测法术]]'''观察其形状和颜色。大部分人的壳颜色都有细微差别，因巧合而同色的情况'''极为罕见'''。

天生缺陷、严重的物理冲击、精神疾病、特定的魔法都可能使灵壳破碎或丧失。'''失去壳的庇护后，原本置于其内的魂质会不断向天界上浮'''。

=== 魂质 ===

填充于壳内的流体，通常是浅白色的，因被灵壳的颜色遮盖而难以直接观察。

其中承载了'''记忆、情感、思想与个体意识'''。

魂质在灵壳内时，会持续向外辐射一种被称作[[魔力]]的能量。

'''生物无节制的恶行会使魂质被罪孽污染。'''详见：[[魂质污染]]。

== 灵魂颜色 ==

即灵壳的颜色。它是琉诺菲拉最基础的身份标识之一，[[伊阿珀王国|伊阿珀]]地区还诞生出了独特的魂色占卜文化。

绝大多数灵魂的颜色都较为鲜艳，颜色会遗传，但通常有细微区别。
=== 无色灵魂 ===

特指因'''灵壳无色透明'''，以至于可直接观测到魂质的灵魂，数量'''极为稀少'''。无法进行任何形式的同频连接。因其特殊性而被灵魂学家视作优秀的研究材料。

[[无色灵魂|无色灵魂的拥有者]]总是会有肉体或精神上的残疾。

=== 纯黑灵魂 ===

技术上不可能存在。

=== 颜色无法识别 ===

'''一种异常状态'''。灵壳被人为改造，以至于拥有多种颜色时，[[灵魂侦测法术]]和[[天界]]的灵魂回收系统皆会无法正常观测，产生错误。

== 同频连接 ==

所有生物都能在一定程度上，与灵魂颜色完全相同且可认知到的存在形成'''心灵与力量上的连接'''。这种连接使他们可以无视一切阻隔，进行无需语言的沟通，且共享魔力。

[[众星历]]100年时，与太阳同为<span style="color: #ffffff; text-shadow: 0 0 4px #ff0000, 0 0 8px #ff0000, 0 0 12px rgba(255,0,0,0.5);">炽白色</span>灵魂的[[光辉]]引发了[[奥西里翁#永夜诅咒|严重的灾难]]。此事之后，'''炽白灵魂不再出现。'''


同频连接也是[[深黯之底]]中囚徒影响现世的主要手段：它们只能干涉与自己灵魂颜色同频的事物。

== 灵魂学的研究 ==

[[玛纳泽永久契约联邦]]和[[伊阿珀王国]]的学者对灵魂进行了深入的研究。在众星历2026年的当下，以下技术已成为可能。

*从生物体内提取出灵魂。

*向魂质中注入记忆和情感。

*对灵壳的切割，重组，拼贴。
