记忆。最终的成品就被称为人造灵魂。

# 玛纳泽永久契约联邦

- 原站版本时间：2026-09-26T10:54:34Z


'''玛纳泽永久契约联邦'''是一个由24座城市组成的城市联邦国家，坐落于[[科塞特斯海]]中的日月两岛及其周边浮岛群上。各城市拥有较高自治权，并通过共同签订的永久契约维系联邦关系。

这里是世界上最著名的魔法工业中心，也是无数法师、学者、冒险者向往的国度。这里拥有高度发达的魔法技术、数量庞大的法师以及收藏着无数知识的[[联邦图书馆]]。

对于许多人而言，'''玛纳泽代表着知识、财富与可能性'''。但与此同时，过高浓度的魔力也给这片土地带来了无法避免的影响。



== 地理 ==

玛纳泽以两座主岛为核心，东侧的岛屿名为[[日之岛]]，西侧的岛屿名为[[月之岛]]，两座岛屿因形状分别近似圆日与弯月而得名。

每座岛上各有12个城市，在日月两岛间还点缀着数十座微型浮岛，而城市之外的土地大多为危险的森林。

由于空气中长期存在高浓度的[[魔力]]，玛纳泽的森林拥有极其丰富的生态环境。泛紫光的沼泽，淌血的小溪，永远燃烧的森林……这种景色在郊外并不稀奇。

除此之外，森林中还存在着大量因[[魔力]]影响而发生变异的独特物种。诸如荧光羊与结晶蜥一类的生物不断吸引着学者与冒险者前往郊外探索。

== 历史 ==

'''玛纳泽是琉诺菲拉最年轻的国家。'''

在[[众星历]] 1426年前，这里还是一片无人认领的荒原。而在六百年后的今天，玛纳泽已是世界的魔法工业中心，与积淀近千年的[[伊阿珀王国|伊阿珀]]并称灵魂学的两极。

=== 维德拉恩的废墟 ===

[[科塞特斯海]]中的日月两岛曾属于[[维德拉恩王国]]。这个国家留下的东西太少，如今人们只知它毁于一场惨烈的战争——[[欧德戴恩]]用某种前所未见的武器犁平了这里，随后掉头离去，没有留下一兵一卒。此后二十余年间，日月两岛无人涉足。至于一个打赢了的国家为何要放弃已经到手的土地，当时没有人想得明白。

[[众星历]] 1426年，一群年轻的[[精灵]]学者乘船抵达日之岛的东岸。他们中的大多数来自[[伊阿珀王国|伊阿珀]]，厌倦了那里论资排辈的学术传统。领头的是个灵魂学家，名叫'''[[凯洛斯·玛纳塔]]'''，他想建立一个知识共享的学术天堂。

=== 最初的契约 ===

年轻的学者们面临一个古老的困境：知识是有主的。法师们敝帚自珍，学派之间壁垒森严，一项发现往往要在一个家族内部烂上几代人。凯洛斯认为，这正是[[伊阿珀王国|伊阿珀]]停滞的根源。

直到[[众星历]] 1431年，凯洛斯完成了'''[[魔网]]'''，并与之签下最初的契约。

契约的具体内容与魔网的原理至今仍是联邦最高级别的机密，但它的效果人尽皆知：玛纳泽的公民可以凭借[[星纹徽章]]接入魔网，共享其内的魔力与知识。贡献的知识越多，能从魔网中调用的魔力就越多。

=== 玛纳泽的发展 ===

魔网织成后的十余年间，接入魔网的学者聚落迅速膨胀，最终连成了城市。
[[众星历]] 1448年，日之岛上的前六座城市共同签署了永久契约，'''玛纳泽永久契约联邦'''正式成立。

而凯洛斯在此之后便退隐，再未公开露面。联邦的官方记载称他“将余生献给了魔网的维护工作”。

此后的扩张速度在琉诺菲拉的历史上没有先例。

*[[众星历]] 1502年，[[联邦图书馆]]的藏书量超过[[伊阿珀皇家生物科学院]]。
*[[众星历]] 1610年，月之岛的首批城市落成，联邦城市数量增至十四座。
*[[众星历]] 1783年，玛纳泽的魔导具出口额跃居世界首位。
*[[众星历]] 1891年，第二十四座城市[[星穹城]]落成，成为联邦新首都。



== 城市 ==

与危险的森林不同，玛纳泽的城市区域经过大量魔法工程改造，每座城市都被浅蓝色的透明魔法防护罩包裹。防护罩由[[律刃]]维护，隔绝森林中的危险生物与紊乱的天气。

城市气候受人工干预，全年保持相对稳定的环境，农业生产也因此十分发达。

城中除开简单的民房外，高层的法师塔也是玛纳泽城市景观的一部分。这些建筑普遍经过防火、防爆处理，以最大程度减少魔法事故带来的损害。

这里的道路总是干净而宽敞，其上还铺设着刻有符文的引路砖，以及可在夜间提供照明的月长石。

不过，即使是高度发达的城市区域，也无法完全消除魔力的影响。偶尔，人们仍然会听见远处传来的爆炸声，看见天空中突然出现的未知物体，或者发现某座建筑突然改变了形态。

但玛纳泽的公民早已见怪不怪，因为有[[律刃]]负责快速处理这类事故。

== 居民 ==

与其他国家不同，玛纳泽的大多数人口并非本地原住民，而是后来迁入的学者和法师。[[联邦图书馆]]吸引着一批又一批有学术理想的人来到玛纳泽，签下契约、分享知识、领取[[星纹徽章]]，成为联邦公民。

在玛纳泽，可以看见许多不同的种族。甚至就连受其他地域排斥的[[魔人]]，也可在玛纳泽正常地生活。

由于玛纳泽重视知识与创新，居民的社会地位并不完全取决于出身、种族或财富，而主要取决于其对知识、魔法与联邦发展的贡献。

衡量这份贡献的，是[[星纹局]]的认证制度。通过认证的法师会获得升级后的[[星纹徽章]]：铜星授予刚获认证的新晋研究者，银星与金星代表更为卓越的成就，而最高等级的伯利恒，则是整个联邦的至高认可。

正因如此，在玛纳泽，一个出身普通的年轻人，也可能凭一己的研究成果，赢得大量资源与广泛的社会认可。

具体居民见此：[[玛纳泽人]]

== 魔法工业 ==

玛纳泽境内的魔力浓度远高于其他地区，因此这里的魔法工业发展程度远超其他国家。大量的魔导具和卷轴从玛纳泽的工厂中被制造而出，由商船运往全世界。魔法玩具也是玛纳泽的特产之一。

某些冒险者发现，将武器在玛纳泽的森林中放置一段时间，武器就有可能自然生出附魔效果。当然，其效果可能是使剑发光，也可能是使剑能开口唱歌。

大量魔法物品出口为联邦带来了巨大的财富，使玛纳泽成为世界重要的经济力量之一。

== 知识与文化 ==

玛纳泽首都[[星穹城]]的'''[[联邦图书馆]]'''收藏着数量庞大的书籍。从基础魔法技巧到失落文明的历史，从实用工程技术到古老传说，几乎所有领域的知识都能在这里找到。

图书馆不只是藏书之地，也是玛纳泽注册法师制度的核心。任何人只要做出独创性的魔法成果或重要发现，便可向'''[[星纹局]]'''提交申请，将成果收入馆中；通过审核后，即可获得注册法师的身份，其[[星纹徽章]]也随之升为更高等级。

注册法师能调用远比常人丰富的资源——图书馆的阅览权限、免费的实验场地和研究材料，以及联邦提供的其他支持。等级越高，可动用的资源也越多。因此，一份足够出色的研究成果，往往就是一个人在玛纳泽向上攀登的起点。

== 契约制度 ==

契约是玛纳泽社会运行的基础。每一位公民都以自己的星纹徽章为媒介，同联邦契约事务厅——[[契约之屋]]签下了具有魔法效力的契约。这些契约规定了公民在社会中的权利与义务，从日常行为规范，到重罪的惩处，均在其列。

通过握住自己的星纹徽章，公民可以随时查阅契约中的条款。对于大多数玛纳泽人而言，契约并不是限制自由的枷锁，而是维持这个庞大魔法社会稳定运行的重要基础。也有别的声音认为，这种无处不在的契约正在逐渐改变自由一词的本意。

== 政治 ==

玛纳泽是一个以契约维系的城市联邦。24座城市各自管理内部事务，拥有独立的财政与市政机构。而[[魔网]]、契约、防护罩与对外事务则由联邦统一管理，不在各城市的自治范围之内。

=== 玛纳泽理事会 ===

'''联邦的最高权力机构，由24座城市各自派出的代表，以及五名大法师共同组成。'''

城市代表由各城公民大会选举，任期四年；大法师由全体金星级以上注册法师选举，任期七年。大法师不隶属任何城市，负责对联邦决议进行技术审查。若认为某决议技术不可行，大法师可行使暂停权，要求重新审议；城市代表可以三分之二多数驳回暂停。

理事会的主要事务包括：拟订联邦法律与契约条款、审议财政预算、任命直属机关的负责人，以及决定外交、战争等国家级事项。

各城市不得单方面退出永久契约联邦，但可向契约仲裁庭提出不公申诉。仲裁庭由大法师、城市代表、星纹局、契约之屋各推荐一人，另加三名金星级法师组成，负责解释契约与联邦法律。

=== 直属机关 ===

理事会下设三大直属机关，三者互不统属。三机关间日常权限争议由联邦协调委员会处理，重大冲突由理事会仲裁。

*'''[[星纹局]]'''：负责法师的注册与认证、[[星纹徽章]]的发放与监管、注册法师的资源配给，以及[[魔网]]的日常维护。其下属的'''知识与遗产局'''负责统筹入库的研究成果，将其编入[[联邦图书馆]]并进行版权保护。

*'''[[契约之屋]]'''：负责契约的签署、执行，以及违约事件的处理，在各个城市中立有大量分部。其下属的执法部与'''符文卫队'''负责实际的拘捕与惩处。

*'''[[律刃]]'''：负责应对战争、天灾、魔兽袭击等一切外在威胁，并维护包裹着每一座城市的魔法防护罩。

== 对外关系 ==

'''玛纳泽对外开放而友善，从未主动发起过战争。'''

联邦的人口几乎全部来自国外。[[联邦图书馆]]的名声传到哪里，哪里就有年轻人收拾行囊——他们大多是各自国家花了几十年培养出来的学者。

移居者需要先与[[契约之屋]]签下契约，将自己所掌握的知识提交至[[星纹局]]，通过审核后方能领取[[星纹徽章]]，正式成为联邦公民。这些知识随即被编入[[联邦图书馆]]，向所有持章者公开，从此成为玛纳泽的一部分。

=== 伊阿珀王国 === 

'''灵魂学研究的另一大中心，也是玛纳泽最大的人才来源。'''伊阿珀的学术传统论资排辈，而在玛纳泽，一份足够出色的成果就是全部的资历。因此，伊阿珀每培养出一位不甘心的天才，往往就是给玛纳泽送去一位新公民。

该国与玛纳泽之间从未建立正式外交关系，但两国边境的港口城市却维持着繁忙的"灰色贸易"。贵族们一边在宫廷中痛斥玛纳泽是"知识的窃贼与娼妓"，一边派遣家族中的次子、私生子和政治失意者前往玛纳泽——美其名曰"流放"。

=== 光辉教 ===

世界上最大的宗教，视[[魔人]]为被魔鬼附身之物。而玛纳泽是少数允许魔人正常生活的国家之一，因此双方关系长期冷淡。

玛纳泽的官方立场是：一个人的价值由其贡献决定，与他过往的罪孽无关。

=== 欧德戴恩 ===

西北大陆的超级强国，与玛纳泽隔海相望，也是六百年前毁灭[[维德拉恩王国|维德拉恩]]的国家。

它与几乎所有邻国交恶，唯独从未对玛纳泽显露过兴趣。毕竟早在众星历 1406年，欧德戴恩人就全面撤出了日月两岛。
