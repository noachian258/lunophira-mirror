造物外，所有的灵魂皆由园艺师制作。'''

[[众星历]]-3610年，园艺师从太阳中打捞出了除工程师和法官之外的其他管理者。

[[众星历]]-3590年，园艺师认为黑色的世界死气沉沉，只有高悬于天的太阳拥有活力。
为改变现状，她将<span style="color: #ffffff; text-shadow: 0 0 4px #ff0000, 0 0 8px #ff0000, 0 0 12px rgba(255,0,0,0.5);">炽白</span>的阳光拆成了数之不尽的<span class="rainbow-text">色彩</span>，赋予了万物色彩各异的[[灵魂#灵壳|灵壳]]。从此，万物有了颜色。

[[众星历]]-3510年，工程师设计了第一批动物的躯体，而'''园艺师赋予了它们灵魂'''。她自太阳中分离出了可以承载感情与记忆的魂质，又将这些魂质倒入了灵壳中。

众星历-1397年，'''园艺师创造了[[人]]的灵魂'''。她所用的方法与创造动物灵魂时大致相同，但为装下更多魂质，承载更复杂的情感，人的灵魂要大得多。

众星历 1年，经过长期的调试，'''人的结构终于完善'''。
第一批完成的人睿智而善良，但太过弱小。园艺师认为色彩各异的人们需要一个强大的领导者，于是将未被拆分的<span style="color: #ffffff; text-shadow: 0 0 4px #ff0000, 0 0 8px #ff0000, 0 0 12px rgba(255,0,0,0.5);">炽白色</span>灵壳赋予了一位新生儿，与太阳同色的人类[[光辉]]就此诞生。

众星历 100年，[[光辉]]因被日光烧毁而死，她的灵魂与[[奥西里翁]]的阳光一同消失了。为防止此种灾难再现，园艺师不再制作<span style="color: #ffffff; text-shadow: 0 0 4px #ff0000, 0 0 8px #ff0000, 0 0 12px rgba(255,0,0,0.5);">炽白色</span>的灵壳。

众星历 1247年，[[伊阿珀|伊阿珀王国]]皇室持续内部通婚，大量无色灵魂由此诞生。为回收这些残次品，园艺师与最早的灵魂学家[[奥德维尔·布拉瓦茨基]]取得了联系，引发第一次[[无色献祭]]。

此后的时间中，园艺师一边补充着灵魂的总量，一边注视着这个世界。

# 天界

- 原站版本时间：2026-09-02T12:53:51Z

天界是负责'''净化与回收'''生物[[灵魂]]的场所，由工程师在[[众星历]] -3590年创造。其入口位于琉诺菲拉穹顶的最高点，仅有灵魂与[[管理者]]、[[清扫者]]可以进入其中。

== 结构 ==

天界浮于云上，'''是独立于现世的空间'''。其内部包含十二座由未知白色金属构建的工厂，一处用于储存灵魂的厂房，以及[[法官]]所在的审判庭。每座工厂中都有上万台持续运行的白匣子，[[工程师]]和[[园艺师]]会定期对这些白匣子进行维护。

== 白匣子 ==

白匣子是具有多种功能的一体化机械设备，看起来像是发光的白色方块，前后两侧的底部各有一个输入口和输出口。它会根据输入灵魂的受[[魂质污染|污染]]程度，自主切换处理模式。

*无污染的灵魂将会被'''直接回收'''。

*轻污染的灵魂将在'''净化后回收'''。

*中污染的灵魂将会存进厂房，由清扫者定时'''运往[[地狱]]'''。

*重污染的灵魂将会使白匣子发出警报，呼叫'''法官将其带入审判庭处理'''。


无色或颜色异常的灵壳会致使白匣子的检测系统失效，此时白匣子亦会发出警报。

=== 净化 ===

执行净化程序时，白匣子将调用内部的日燧灯，对魂质进行十秒左右的高强度照射。罪孽将在日光中分解，化为极细微的尘埃，最终自行消逝。

高于十秒的照射将损害魂质本身的结构。因此，该方案无法用于清除较重的罪孽。

=== 回收 ===

执行回收程序时，白匣子会先将壳与质分离。

魂质中原有的'''记忆、情感、思想会被清除'''，只保留个体意识。

随后，白匣子会对灵壳进行'''抛光与补全'''。

处理后的二者会分别投入世界的循环系统，被分配给合适的新生命。

== 审判庭 ==

审判庭位于工厂群的中间，本质是一个巨大的积分球<ref>一种能使光线均匀散射的白色球体</ref>。需受审判的灵魂将被放置在审判庭的中央，其色彩与形态会被反射至室内的每一寸墙壁上，以供[[法官]]仔细观察，做出判决。

审判的结果通常有三种。

*无罪释放：发生在因灵壳异常而报警时。[[法官]]会丢弃异常的灵壳，单独回收魂质。

*重罪入狱：确认罪孽已经重到无法净化后，法官会将之押往[[深黯之底]]。

*死罪执行：当深黯之底的隔离手段完全无效，且受审的灵魂已经威胁世界的存在本身时，法官会直接抹除其灵魂。
这种手段会使[[星空]]中的记录出现大量错误，甚至可能导致太阳出现异常。因此非必要绝不使用。

# 奥西里翁

- 原站版本时间：2026-09-02T12:53:33Z

'''奥西里翁是一座立于白沙漠之上的独立城邦'''。近海与城市边境的两层迷雾使此城与世隔绝。这里的'''居民皆为[[蛇人]]'''。受永夜诅咒与大寒潮的影响，此处人口稀少，封闭而落后。

具体住民见此：[[奥西里翁人]]

== 地理 ==

'''奥西里翁是琉诺菲拉东北大陆上唯一的文明。'''

奥西里翁所在的白沙漠位于东北大陆的中央。白沙之下有一座名为“余烬泉”的巨大热泉。

永夜诅咒使得东北大陆失去了太阳，没有热源的北方已沦为荒原。诅咒的范围仅限于东北大陆与其近海。

在冻结的海上行走五公里左右后，能观测到太阳从无到有浮现，海水逐渐恢复流淌的奇观。

极端的温差在海面上生成了终年不散的浓雾，因此环绕东北大陆三面的这片海域被称作[[迷雾海]]。往南越过迷雾海，可到达[[长溪雨林]]。

== 气候 == 

'''奥西里翁的地表温度常年在28℃至36℃之间'''。自余烬泉中涌出的庞大热量被沙层吸收，为冷血的蛇人居民带来了生存所需的温度。

'''在城邦之外，该地区的温度可低至-60℃'''。地表温热的水汽在上升时遭遇高空严寒，受制于强烈的逆温效应无法散去，最终形成了几公里厚的湿热雾气，笼罩在城邦上空，经久不散。

== 历史 ==

[[众星历]] 100年之前，东北大陆生活着[[人类]]与[[蛇人]]，'''两族之间的冲突持续不断。'''当时这里还以气候炎热闻名，居民们将脚下的土地称作“波尔所”，意为“在阳光下的”。

众星历 100年 第三幕 第七日，大寒潮袭来。'''人类与蛇人放下嫌隙，携手造船逃往海外。'''
但谁也没想到，在他们踏出东北大陆的土地前，'''太阳会先一步熄灭。'''

此事之后，'''东北大陆发生了翻天覆地的变化'''，再也没有人提起“波尔所”这个名字。

=== 永夜诅咒 ===

众星历 100年 第六幕 第二日，人们造出了一艘大船。如果一切顺利，船会载着他们一路南下，前往未知的丰饶土地。出航前，两族的代表并肩向太阳宣誓团结。三秒钟后，太阳熄灭了。几小时后，人们绝望地发现月亮也未按时升起。自此，东北大陆陷入了永恒的无光之夜。

消逝的日光带走了团结。人类指责蛇人用巫术偷走了太阳，蛇人控诉人类的背叛，战争一触即发，但只持续了一天。东北大陆的气温迅速下降，人类于寒冷中颤抖，而失温的蛇人当场僵直。将仇恨抛在脑后，幸存的居民们开始了逃亡。

=== 逃亡的终点 ===

人类对寒冷的耐受力更强一些。他们支起了那艘大船，顺着迷雾海的洋流而下，到达了[[长溪雨林]]。

而无数的蛇人来不及逃亡，就冻死在了海边。唯有退守白沙漠的沙蟒部族，与少数幸存的外界蛇人得以繁衍。

=== 奥西里翁的建立 ===

沙蟒部族一直生活在白沙漠中的余烬泉之上。对别的蛇人来说，这里太过炎热，而对于沙蟒，这样的温度刚刚好。寒潮对它们几乎没有影响，外界的二族仇怨也传不进沙漠里。直到永夜诅咒降临，有外界的蛇人逃进沙漠，沙蟒们才察觉到不对劲。

了解这一切后，沙蟒们对外部蛇人的遭遇表示同情，并邀请他们加入部族，一同构建属于蛇人的城市奥西里翁。此后的近两千年中，奥西里翁逐渐从部族聚落发展为独立城邦。

== 政治 ==

奥西里翁没有单一领袖，最高权力机构是源泉议会，由三名执政官组成。

*守泉人：从沙蟒诸家族中选出。负责维护热泉的物理运转、监测地震，并起草考古队热量配额。配额须经议会两票通过方可执行。

*破雾人：由陆上的成年蛇人选举产生，每五年一任，可连任一次。负责外交贸易、历法同步、组织考古队，并起草外贸所得肉食的分配方案。

*筑基人：由地穴居民选举产生，每五年一任，可连任一次。负责菌田、内部配给、基础建设、抗震避难与丧葬事务。

三者权力完全平等，任何重大决策都需要至少两票通过。

如对决策的结果有异议，任何成年蛇人都可以站出来，提出紧急异议，依热泉之礼展开一场特殊的辩论。如果三日内没能说服任何一位领袖，提出者将被处以不定时长的劳役，并短暂剥夺异议权。

=== 热泉之礼 ===

蛇人们从历史中学到了教训，极端环境中的激烈冲突无异于自杀。因此，奥西里翁发展出了一套独特的辩论传统，蛇人们称其为“热泉之礼”。

任何争议都必须先进入一段冷却期。在此期间，涉事双方被要求分开独处，不得直接接触或对话。一名由源泉议会指定的中立调停人将往返于双方之间，传递各自的陈述与逻辑。冷却期的长短取决于争议的严重程度，短则数小时，长则数日。生理上的冷静会迫使心理上的克制。

若私人调停无法解决争端，或争议的性质触及了资源分配的变更、跨阶层的矛盾，乃至对“热泉之礼”本身的破坏，该议题便会被送上白沙圆庭，进行公开辩论。

白沙圆庭位于余烬泉的主脉之上。室内弥漫着温热的水汽，不息的流水在脚下的岩层中嗡鸣回响。

辩论时，争议双方并排站在共鸣室的中央，源泉议会选出的三名裁决者环绕而坐，所有成年蛇人都可以在周围的阶梯上旁听。辩论没有时间限制，冗长的质询和陈述会一直持续下去，直到某一方说出那句标志性的宣言：
<blockquote>
“我完全接受你的观点。”
</blockquote>
整个过程可能持续数天甚至数周，效率极为低下。但得益于此，奥西里翁两千年来从未爆发过内战。

== 生态 ==

余烬泉几乎有整个白沙漠那么大，'''任何蛇人都能轻易地享受到这股温暖'''，而居于其上的蛇人们不得不忍受频发的小震。


低矮的房屋与地穴围绕热泉修建，不耐高温的蛇人居于陆上，喜热的蛇人盘旋于地穴中。


奥西里翁的食物来源单一：地穴菌田中种植的真菌依赖荒原冻土下的古代有机物作为养料，肉食则完全依赖海盗灵商贩的进口。食物的匮乏锁死了奥西里翁的上限，城邦因此'''长期停滞'''。


'''将死的蛇人会主动潜入余烬泉的支流中'''。他们恐惧寒冷，以至于宁愿在温暖中'''溺死'''。

== 文化 ==

失去太阳后，日与夜的界限模糊，蛇人们便以余烬泉涌动的次数来计算日期。直到众星历600年左右，奥西里翁人同[[迷雾海]]中的[[概念灵|海盗灵]]展开文物贸易后，他们的历法才开始与外界同步。

白沙漠外的荒原下埋着无数死在寒潮中的枯骨。源泉议会会定期派出考古队，挖掘被埋没的古代文物与生物遗骸。

在-60℃的荒原上，考古是一项以余烬泉的热量为生命线的高危事业，其成果也是城邦换取肉食的重要筹码。
详见：[[奥西里翁考古队]]

古时的蛇人将永夜称作诅咒，而如今的学者们从文物中得出了更进一步的答案。

就在[[塔尔塔洛斯]]因[[光辉]]之死而四季如春的同时，奥西里翁失去了太阳。两者之间的联系过于明显，奥西里翁的主流声音认为，是[[光辉]]偷走了东北大陆的太阳，将之献给了[[塔尔塔洛斯]]。
