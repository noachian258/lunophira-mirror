== 角色介绍 ==

薇尔安·玛纳塔出身于[[伊阿珀王国]]，原名薇尔安·月鸣，嫁给[[凯洛斯·玛纳塔]]后改姓。现今为[[玛纳泽永久契约联邦]]的伯利恒法师。也是'''星纹局下属魔网维护科的主任'''。

'''薇尔安与[[流明]]是唯二受契约许可，可直接接触[[凯洛斯·玛纳塔|魔网核心]]的法师。她掌握作为联邦最高机密的魔网维护技术，也是唯一一个有权不对魔网公开自身研究成果的法师。'''

与其余的六位伯利恒法师不同，薇尔安作风低调，从不参加玛纳泽理事会的选举。她如自己的丈夫一样，将全部身心都倾注在了维护魔网的事业之上。

以上，是'''大多数玛纳泽人对薇尔安的印象'''。

== 事迹 ==

薇尔安和凯洛斯来自同一个[[精灵|月精灵]]部族，二人从小就是一起学习、一起玩耍的伙伴，成年后更是携手考入了伊阿珀的知名学府卡斯特林学院，一同在灵魂学专业深造。

彼时的薇尔安选择了时下需求最高的人造灵魂技术作为研究方向，而凯洛斯则在自己更擅长的离体灵魂保活技术方面深造。两人毕业的那一年正赶上[[伊阿珀皇家生物科学院]]扩招，薇尔安便与凯洛斯做下约定，要是能一起被聘用，就在首都切斯伯德购房定居，结婚生子。然而薇尔安进了科学院，凯洛斯却因为研究方向过于冷门而被拒绝，两人的婚约也因此暂缓。

为了安抚落榜的爱人，薇尔安开始偷偷把皇家科学院藏书室里的典籍抄写在手臂和大腿上，用法袍遮住，一点一点地带回家供凯洛斯阅读。

此举点燃了他心中的希望之火，却是她噩梦的开始。

=== 黑之卷 ===

根据禁书区《黑之卷·第十四》的记载，在世界之外，设立着[[深黯之底|某座用于囚禁神明的监牢]]。伊阿珀人世世代代崇敬的影之造物主就身处其中，而除祂之外，狱中还收押着人们所犯下的罪恶：傲慢、贪求、愤怒、暴食……

读到这一内容的薇尔安大为震惊，当即进行抄录，并在下班后向凯洛斯分享了这一颠覆认知的知识。

在此之后又过了大概三年，凯洛斯就黑之卷的分享向薇尔安表示了感谢，并提出自己已经并不想继续待在伊阿珀学习。对平民和精灵的双重歧视使得他的道路异常崎岖，与其留在这里与古卷一同腐朽，不如在新的大陆创造真正的理想乡。凯洛斯认为，将乌托邦带入现实的技术已经有了眉目，而伊阿珀并非合适的土地。

=== 伊甸园 ===

薇尔安总是信任凯洛斯。毫不知情的她随百余名受凯洛斯鼓舞的精灵学者一起，搭船上了[[玛纳泽永久契约联邦|日之岛]]的岸，这片危险而荒芜的土地在她眼中成了自己与爱人的伊甸园。

搭起第一处营地后，在众多学者的见证下，凯洛斯答应履行与薇尔安的婚约。薇尔安把白色的法袍当婚纱披上，在光秃秃的草地里和凯洛斯办了一场极其简陋的婚礼。她不怎么在乎形式上的缺陷，满心只想着面前的男人终于能属于自己。而他的目光飘忽，总是往旁边的帐篷里看。她张口说出“我爱你”，却换来了他一句下意识的“对不起”。

=== 破碎 ===

婚礼的第二天，醒来的薇尔安枕边空荡。她走到临时搭建的实验室里，看见自己所爱的男人躺在大理石板的中央，浑身是血。他的灵魂被放置在透明的仪器里，灵壳四分五裂，仪器边上摆着一枚闪着青蓝色光芒的星型徽章。她颤抖着将之拿起，摩挲着上面的刻纹——那是后来被称作[[星纹徽章]]的东西。

她立刻将灵魂置回凯洛斯的体内，哭泣着质问他这一切到底是怎么回事。在她的逼问下，凯洛斯将整个[[魔网计划]]和盘托出。自此，薇尔安终于明白了什么是他口中的理想乡。

=== 执念 ===

在凯洛斯的劝说与现状的压力下，薇尔安不得不接受了凯洛斯的计划。她不再干涉凯洛斯如何处理自己的灵魂，但作为代价，在丧失意识后，凯洛斯的肉体必须由她亲自维护，其他任何人都不可接近。在她看来，从凯洛斯决定执行魔网计划的那一刻起，她挚爱之人的灵魂就已经被抵押给了那只被称作[[普罗维登斯]]的概念灵。灵魂已经失去，她唯一能做的就是抓住肉体。

在1448年的永久契约仪式之后，凯洛斯因灵壳缺失严重带来的剧痛而完全失去行动能力，只能在具有魂质保存功能的水晶棺中度过余生。为缓解凯洛斯的痛苦，薇尔安利用魔法抽走了他魂质中余下的记忆与情感，将之封存在魔导书中日夜翻看。自此之后的凯洛斯与仅会呻吟的肉块无异。也是从此开始，切割凯洛斯灵壳的工作由薇尔安代为完成。

众星历1997年，精灵千年的悠长寿命也已过了大半，凯洛斯的肉体开始老化，灵壳也即将用尽。为了延续玛纳泽的永久契约，更为了再次见到那抹鲜活的青蓝，薇尔安开始研究如何定向制作出<span style="color: #1035b9;">'''青蓝色的[[灵魂]]'''</span>。

如今，这项技术已接近成熟。以飞蛾[[灵魂]]为原料的青蓝色[[合成兽灵]]已能在实验室条件下存活六个月之久。

# 蛇人

- 原站版本时间：2026-09-02T12:54:41Z

蛇人是一种较为常见的亚人，也是[[兽灵]]的一种。

== 外形 ==

'''蛇人的上半身为标准的人形，下身为覆有鳞片的蛇尾。'''鳞片的颜色多样，绿、黑、紫、金等颜色最为常见。

其口部长有尖而长的牙，瞳孔竖直。

== 特点 ==

蛇人的尖牙使得他们善于撕咬猎物，部分亚种的口部还可分泌毒液，毒性从些微的麻痹到瞬间致死不等。通常来说，带毒的蛇人会拥有更高的社会地位。

其双眼可以捕获周围事物的热量，此种特点使得他们在黑暗中仍能清晰地分辨方向，追踪猎物。

蛇人的血液冰冷，因此极度畏寒。暴露在寒冷之下几分钟就足以让血液凝固，全身僵直。

== 分布 ==

蛇人大多分布在西南大陆之上，也有可在水中生存的亚种。其中[[珀西平原]]的蛇人居民最多，东北大陆的[[奥西里翁]]是唯一一个仅由蛇人居民构成的城邦。

== 寿命 ==

生活状况良好的蛇人可存活60~80年左右，其水平与人类无异。需要注意的是，他们的健康水平受周围气温的影响严重，生活在寒冷或过度炎热环境中的蛇人预期寿命不足上限的一半。

== 文化 ==

蛇人将蛇视为自己落后的、原始的、可笑的先祖，几乎毫无崇拜之情。有的蛇人甚至会故意虐杀蛇供他人围观取乐。奥西里翁是个例外，东北大陆的情况使得这里几乎找不到什么活的动物，在万物死绝之地，可笑的先祖成了唯一与他们相伴的活物。这让偶然在白沙之间寻得的蛇变成了奥西里翁人唯一的崇拜对象。

对狩猎和捕食的渴望刻入了蛇人的基因之中，他们中的每一人都曾渴望过亲自以尖牙撕开猎物表皮的快感。因此，人类与精灵等文明程度较高的种族将蛇人视为嗜血的野蛮种族，[[伊阿珀王国]]、[[日轮国]]等地更是从政策上排斥蛇人移民的到来。

互相触碰尾尖是蛇人最常见的招呼模式。在面对其他种族时，一些蛇人仍会下意识地做出此类的举动。
