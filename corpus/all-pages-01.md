# 人类

- 原站版本时间：2026-09-02T12:54:02Z

人类是琉诺菲拉'''最初也是最多的智慧生物'''，和[[亚人]]一同并称为[[人]]。

== 外形 ==

人类的'''躯干光滑，无翼无尾，短而圆的双耳分布在头两侧'''。各民族的人类在肤色和发色方面略有区别，但总体差异不大。

正因人类的形态稳定而缺乏特异特征，学者们便以人类的体态为基准，将这一标准形态命名为'''"人形"'''。

在此之后，判定某一[[亚人]]与人类的亲缘远近，乃至界定一个新发现的生物是否属于[[人]]的范畴，'''皆以其偏离人形的程度为参照'''。

== 特点 ==

与拥有各种能力的[[亚人]]相比，'''人类最大的特点就是他们的普通。'''
既不像[[矮人]]般长寿，也不似[[自然灵]]般多变。高温和低温都会使人类快速失去生命，他们还不能消化矿物，不能消化毒物，需要蔬菜或肉类等营养维持生存。

但人类并没有因自身的平凡和脆弱而止步。他们凭借后天的学习与努力，达到了不输于任何一族的成就。

学者[[克蕾姬奎亚]]以一己之力推动了整个世界的灵魂学发展，远古贤者[[光辉]]直到今日仍被崇拜。除此之外，人类的活动还催生了不少其他种族。

*人类与[[自然灵]]结合，诞生了[[精灵]]。

*人类与[[龙]]签订血契，诞生了[[龙人]]。

*许多概念自人类的思想中诞生，得到魂质后变成了[[概念灵]]。

*[[克蕾姬奎亚]]研究出了[[灵魂#人造灵魂|人造灵魂]]的技术，制作出了[[合成兽灵]]和[[人偶]]。

诸如此类，不胜枚举。

== 分布 ==

据考古发现，人类至少在[[众星历]] -1300年前就已经存在，比排在第二的[[矮人]]早了700余年。在众星历 -1300年至众星历 元年间，人类的形态仍在不断演化，其中甚至能找到自人类演化为亚人的案例。因此，也有学者认为人类是一切[[亚人]]的原型。

人类广泛地分布于所有陆地之上，只有[[奥西里翁]]是个例外。在众星历 100年的[[奥西里翁#永夜诅咒|永夜诅咒]]发生后，东北大陆的人类基本都逃到了[[长溪雨林]]。

人类难以在水中呼吸，这样的生理构造注定他们与[[苍泪联合]]等海洋城市无缘。

== 寿命 ==

生活状况良好的人类可存活60~80年左右，其中也有较为长寿的个体。目前人类寿命的[[格蕾|最高记录]]是105年。

通常来说，在到达50岁之后，人类的身体机能会迅速下降，进入衰老期。

近年来，由于灵魂学和生物学的发达，部分人类开始采用[[灵壳改造|改造灵壳]]的方式延寿。

== 文化 ==

由于人类的足迹遍布世界，因此他们的文化很难以种族来界定。因此这里只记载人类眼中通用的共识。

*在人类为主的社会中，道德通常是很重要的。身份与秩序也同样被重视。

*各地人类的着装风格不同，但都在遮蔽私处的基础上追求华丽或实用。

*杀人是野蛮而可怕的行为。非必要情况下不应该这么做。

== 角色介绍 ==

光辉诞生于[[众星历]]1年第一幕第一日的[[塔尔塔洛斯]]地区，[[园艺师]]赋予了她与[[太阳]]同色的[[灵魂#灵壳|灵壳]]。

依靠[[灵魂#同频连接|同频连接]]，她能操控部分日光，甚至干涉他人的[[灵魂]]。强大、善良、富有同情心的光辉使用这份力量实现了诸多愿望，挽救诸多生命。

她被奉为最伟大的贤者，是目前世界最大宗教[[光辉教]]的崇拜对象，被视为行于人间的太阳。与此同时，大多数教派还认为光辉是大地的慈悲化身，而[[塔尔塔之龙]]是大地的愤怒化身。
因此，二者被视为同一神祇的两面。

但北方文明似乎并不认可这份信仰。

== 事迹 ==

关于光辉的事迹，有各种不同的记载。

=== 主流说法 ===
据《光辉圣典》记载，光辉睿智而富有同理心。人类文明诞生之初，一切尚在混沌之中。她挺身而出，运用自己的智慧与力量，带领人们建立了塔尔塔洛斯的第一座城市。

她见不得人间的惨剧，若是见了眼盲的孩子，便上前予他光明。若是见了因地震流亡的饥民，便摘来果子给他。向光辉许下愿望的人很多。[[悠久之森的守护者|有人想要永远守护自己的所爱]]，[[烈岩|有人想要能抵御病痛的力量]]，[[莱汀|有人渴望脱离俗世的自由]]，光辉都将之一一实现了。

[[众星历]] 100年 第三幕第七日，天空黯淡失色，[[大寒潮]]席卷世界。衰老严重的光辉拖着疲惫的身体，为救治受难者而奔走。

[[众星历]] 100年 第六幕第一日，冻死者与饿死者的尸体堆遍了塔尔塔洛斯的土地，光辉的身体也越来越虚弱，终于，她倒下了。
绝望的灾民握住她的手，向光辉许下了最后一个愿望——'''请使塔尔塔洛斯四季温暖如春。'''

她让灾民的身体温暖起来，又如此说道：“我将回归大地，永与你们同在。”

愿望实现了。次日，光辉的肉体迸裂，灵魂消散，徒余耀目的金光撒遍塔尔塔洛斯的大地，使得寒潮平息，万物复苏。

从此之后，塔尔塔洛斯再也没有迎来过冬天。人们震撼于这份壮举，将之称为“伟大回归”，自发传颂光辉的事迹。

如此发展至众星历200年左右，光辉教已有雏形，露米那也成了圣都。

=== 其他记载 ===

在北方国家[[奥西里翁]]的记载中，[[众星历]]100年时，随寒潮一同而来的还有[[奥西里翁#永夜诅咒|永夜诅咒]]。目前，奥西里翁的学者普遍认为永夜诅咒与伟大回归之间有所联系，两者几乎完全同时发生。但奥西里翁封闭落后，他们的声音并不被世界所接受。

== 角色介绍 ==

凯洛斯·玛纳塔出身于[[伊阿珀王国]]，在[[众星历]] 1426年时带领百余名精灵学者乘船迁往[[玛纳泽永久契约联邦|日之岛与月之岛]]，一手领导众人建立起了[[玛纳泽永久契约联邦]]。

他以出众的演说能力和剑走偏锋的学术能力闻名。魔网完全由凯洛斯个人研制，其技术细节至今仍是玛纳泽的最高机密，目前尚无任何替代方案能达到魔网的效果。

值得注意的是，自1431年魔网正式建成后，凯洛斯的公开露面次数就逐渐减少。他最后一次露面是在1448年日之岛的永久契约仪式。

对玛纳泽人来说，凯洛斯是一位值得崇敬而又让人深觉遥远的、故事中的伟人。

现今的凯洛斯·玛纳塔早已失去行动和思想的能力，作为魔网的核心被保存在星纹局的最下层，由[[薇尔安·玛纳塔]]负责维护。

== 事迹 ==

幼年的凯洛斯是月精灵部族内远近闻名的小天才。受伊阿珀王国深厚的灵魂学研究氛围所影响，他对此也有了非同寻常的兴趣，二十岁时便和同乡的[[薇尔安·玛纳塔|薇尔安·月鸣]]一同考上了卡斯特林学院，在灵魂学专业深造。
 
=== 起始 === 

只有在人体内的灵魂才算得上生命，而单独的灵魂不过是一个器官——这是伊阿珀人自小便被教育的知识。但凯洛斯却对此表示怀疑。正统说：灵魂是肉体的器官。而凯洛斯说：肉体是灵魂的器官。为了确认自身的观点，他开始研究如何长期保存离开肉体的灵魂，并很快发明了能使灵壳维持活性的技术。

但[[伊阿珀皇家生物科学院]]并不认可凯洛斯的主张和其成果，还因凯洛斯的精灵平民身份而回信嘲笑。碰壁后的凯洛斯一度失意，直到读完[[薇尔安·玛纳塔|薇尔安]]从科学院禁书库中偷偷抄录而出的《黑之卷·第十四》。

=== 黑之卷 ===

根据《黑之卷·第十四》的记载，在世界之外，设立着某座用于囚禁神明的监牢。伊阿珀人世世代代崇敬的影之造物主就身处其中，而除祂之外，狱中还收押着人们所犯下的罪恶：傲慢、贪求、愤怒、暴食……

薇尔安本想向凯洛斯分享影之造物主的真相，而凯洛斯的目光却落在了别处。这世间存在被囚于监牢的傲慢化身。意识到这一点的同时，通体青蓝的巨大十二面体在他脑中闪烁而过。这就是凯洛斯与[[普罗维登斯]]第一次建立[[灵魂#同频连接|同频连接]]。

求知欲促使着凯洛斯主动向普罗维登斯发起心灵沟通。在毫无感情的信息交换之间，他知晓了普罗维登斯的真实身份，也掌握了对方所渴望的东西。两者谈好了交易的雏形：凯洛斯为普罗维登斯提供源源不断的新知识和魔力，而普罗维登斯负责以同频连接的方式定向传送这些东西。这即是魔网计划的雏形。

=== 魔网计划 ===

在与普罗维登斯初次接触后的30年里，凯洛斯一步步地完成了自己对魔网的完整构思。其内容大致如下：

凯洛斯将自己的灵壳切成千万片，制成[[星纹徽章]]，再以契约将星纹徽章和使用者的灵魂绑定在一起。而普罗维登斯通过同频连接干涉凯洛斯的灵壳，即可定向干涉所有持星纹徽章的玛纳泽公民。

作为报酬，普罗维登斯可以获得魔网内全部的知识，还可自由从中调取魔力。
  
就这样，凯洛斯与普罗维登斯签下了最初的契约。他开始对外宣传自己掌握的魔网技术，召集了不少对此感兴趣的追随者，一同前往日月二岛开创一番新天地。

=== 婚姻之后 ===

但凯洛斯的计划里从头到尾都没有考虑过薇尔安——那个爱着他的女人。他甚至不确定自己对薇尔安的感情究竟为何，或许是一起研究的伙伴，或许是从小到大的知心朋友……但他还是在同行者的怂恿与欢呼中，在日之岛上和薇尔安结了婚。

对于凯洛斯来说，这场婚姻就是给薇尔安的交代。因而在此之后，他终于有了将全身心都投入在魔网计划上的勇气。在婚礼的第二天，凯洛斯于临时搭建的实验室中切割了自己的灵壳，制作出了世界上第一枚星纹徽章，效果完全符合预期。

随着演讲中那些美好的愿景一一被兑现，自发前往日月两岛，加入玛纳泽的人也越来越多。凯洛斯亲自为每一位投奔的学者制作了星纹徽章，带领着人们在荒芜的岛上建起高塔，筑起城市。

=== 破碎 ===

血肉撕扯，灵魂分裂的痛苦始终伴随凯洛斯，且随着玛纳泽人口规模的扩大日夜加重，这是切割灵壳和离体保活技术带来的副作用。最终，在出席日之岛前六城的契约仪式后，凯洛斯失去行动能力，彻底倒下，由亲信交给[[薇尔安·玛纳塔]]照看。现今的凯洛斯被抽去记忆与情感，躺在星纹局最底层的水晶棺中，与只会呻吟的肉块无异。

=== 理想 ===

唯一剩下的，或许只有那铭刻在他灵魂深处的理想。知识的开放势必会带来更大的进步，古旧的观念不应成为前进的绊脚石。建立人人平等，研究自由的天堂是他的毕生所求。

魔网的设计并不完备。灵壳微小的碎片难以承受普罗维登斯巨大的魔力流，这些外溢的魔力使玛纳泽郊外产生了严重的魔力污染现象。那些知识与被抽取的魔力，或许也将成为普罗维登斯突破深黯之底的力量。然而凯洛斯却并不害怕这样的未来。因为做出决定之前，他就相信魔网能让玛纳泽的技术实现指数级的增长，后人一定能抢在普罗维登斯突破之前抢先找到压制他的方法。

这是凯洛斯的希望，也是他的<span style="color: #1035b9;">'''傲慢'''</span> 。

== 角色介绍 ==

园艺师诞生于[[众星历]]-3612年，由[[工程师]]从[[太阳]]的核心中打捞而出。

作为[[管理者]]，她的职责是从[[太阳]]的光中采集[[灵魂#魂质|魂质]]与色彩，将其制成[[灵魂]]。园艺师也负责与[[工程师]]一同维护[[天界]]的灵魂回收系统。

园艺师是被爱所驱动的狂热创造者。她对自己的造物抱有高度的期待和溺爱，且热衷于观察它们。为此，她常去阅读[[群星的主人|星空中的记录]]。

她欣赏琉诺菲拉的一切。包括美好的那部分，也包括残酷的那一部分。

但以上皆有例外。[[灵魂#无色灵魂|无色灵魂]]是唯一一个令园艺师反感的造物。它们的灵壳上没有被正确赋予颜色，这直接导致了感情空洞和残疾等各种问题。

'''除太阳与人
